[POST 2]
Naskah:
Klien gak perlu install aplikasi apapun.

Cukup buka link di browser HP, masukin PIN pengaman 4 digit, langsung muncul galeri foto mereka.

Klien tinggal swipe kanan kalau suka, swipe kiri kalau mau lewati. Ada hitungan kuota foto terpilih secara real-time biar mereka gak over-budget. Pas selesai, tinggal klik Kirim.

[POST 3]
Naskah:
Masalah kedua: mindahin 20 foto pilihan klien ke Lightroom.

Biasanya kan fotografer baca list chat WA, terus ketik nama file satu per satu di search bar Lightroom. Makan waktu 20-30 menit.

Di Ruang Bahagia:
Tinggal klik "Salin Filter Lightroom", pilih ekstensi kamera (.CR3, .ARW, .NEF), buka Lightroom, paste di Library Filter.

Semua foto terpilih langsung terisolasi dalam 1 detik.

post_03_screenshot_lightroom.png
